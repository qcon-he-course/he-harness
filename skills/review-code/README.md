`review-code` is Week 3's step 6 reviewer: an independent review of the code that implements an OpenSpec change, after step 5's sensors. It follows `review-change` (step 3): the same finding format and dispositions, the same "For the person" section. What it adds: a verdict on every scenario before any overall view (the reference document's structured per-criterion review), a rule that a test counts only for what it asserts and only if it can fail, and a check of each sensor finding.

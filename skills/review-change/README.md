# review-change

For Week 3 step 3, the review before code (experiment e15), and for the homework. Written on 31 October 2026 from the course's reference document on the independent review harness (`research/notes/2026-08-28-independent-review-harness-reference.md`): the finding format with a falsification line, the four dispositions, a verdict per item before an overall verdict, withholding the author's own assessment, and a closing packet of questions for a person. The "missing, scope added, wrong" brief comes from the Spec axis of Matt Pocock's `code-review` skill (MIT).

The skill does not enforce that the reviewer cannot edit: the `w3-reviewer` layer does, by denying the edit tools.

Not yet tested with and without.
